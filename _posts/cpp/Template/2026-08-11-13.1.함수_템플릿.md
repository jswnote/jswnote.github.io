# Template

프로그래밍 언어에는 프로그래머의 단순 반복 작업을 줄여주기 위한 여러가지 장치들이 마련.   
템플릿은 여러가지 자료형에 대해서 비슷한 코드를 반복해서 작성하는 것을 방지.   


```cpp
int getMax(int x, int y)
{
	return (x > y) ? x : y;
}
```

위와 같은 함수가 있으면 매번 자료형이 다른걸 요구할 때, 매개변수는 reference를 요구할 때 등 어떻게 진행해야할까?    

```cpp
template<typename T> //typename 대신 class가 들어와도 되는데 거의 비슷하다.   
T getMax(T x, T y)
{
	return (x > y) ? x : y;
}

int main()
{
  std::cout << getMax(1, 2)        << std::endl;
  std::cout << getMax(3.14, 1.592) << std::endl;
  std::cout << getMax(1.0f, 3.4f)  << std::endl;
  std::cout << getMax('a', 'c')    << std::endl;

  return 0;
}
```
내부적으로는 컴파일러가 T 자리에 각각 int, double, float, char가 들어갈 일이 있구나라고 알고 있음. 컴파일러가 각 자료형에 대한 getMax함수들을 다 만들고 오버로딩처럼 내부적으로 진행.   


user defined 자료형은?   

```cpp

//cents.h
class Cents
{
  private:
    int m_cents;

  public:
    Cents(int cents)
      : m_cents(cents)
    {

    }

  friend bool operator > (const Cents &c1, const Cents &c2)
  {
    return (c1.m_cents > c2.m_cents);
  }

  friend std::ostream& operator << (std::ostream &out, const Cents &cents)
  {
    out << cents.m_cents << "cents : ";
    return out;
  }
}

//main
template <typename T>
T getMax(T x , T y)
{
  return (x > y) ? x : y;
}

int main()
{
  std::cout << getMax(Cents(5), Cents(9)) << std::endl;
}

```
템플릿은 작동하려면 필요한 기능들이 다 구현되어 있어야함.(operator 등...)    

### instantiation
템플릿에서 T 같은 템플릿 매개변수에 int, double, user defined 데이터 타입 등 구체적인 타입을 적용해서, 그 타입에 맞는 함수나 클래스를 만드는 과정.   

1. 타입 추론(deduction) - 컴파일러가 getMax(1,2)에서 1,2 인자를 보고 T가 int인 것을 알아냄.   
2. 인스턴스화(instantiation) - T에 int를 적용해서 getMax<int>라는 구체적인 함수를 만들어냄.
