# Template

클래스를 템플릿화 해보자.    
만약, 클래스의 멤버 컨테이너에 여러 자료형을 담고 싶으면?   

```cpp
//MyArray.h

#include <assert.h>
#include <iostream>

template<typename T>
class MyArray
{
    private:
        int m_length;
        T *m_data;

    public:
        MyArray()
        {
            m_length = 0;
            m_data = nullptr;
        }

        MyArray(int length)
        {
            m_data = new T[length];
            m_length = length;
        }

        ~MyArray()
        {
            reset();
        }

        void reset()
        {
            delete[] m_data;
            m_data = nullptr;
            m_length = 0;
        }

        T &operator[](int index)
        {
            assert(index >= 0 && index < m_length);
            return m_data[index];
        }

        int getLength()
        {
            return m_length;
        }

        void print()
        {
            for (int i = 0; i < m_length; i++)
            {
                std::cout << m_data[i] << " ";
            }
            std::cout << std::endl;
        }
};
```

```cpp
//main.cpp

#include <MyArray.h>

int main()
{
    MyArray<char> my_array(10); //여기에 특정 자료형 적어줘야함.

    for(int i = 0; i < my_array.getLength(); ++i)
    {
        my_array[i] = i + 65;
    }

    my_array.print();

    return 0;
}
```

## 클래스의 instantiation
MyArray<T>   : 원소 타입 T에 따라 달라지는 클래스 템플릿의 형태. 클래스 템플릿은 클래스가 아니다.   
MyArray<char> : T에 int를 적용한 구체적인 클래스 타입.  
MyArray<char> my_array(10) : MyArray<char>타입으로 만든 객체(인스턴스).
my_array 선언하는 시점에 컴파일러는 MyArray<int> 객체의 크기와 구성을 알아야함. 따라서 my_array(10)이 정의되는 시점이 바로 인스턴스화 되는 시점.  


## 클래스 템플릿은 일반적으로 분리하지 말자.   
만약 클래스의 멤버 함수를 밖으로 빼내면?   
```cpp
//MyArray.h
//print의 함수를 클래스 밖으로 빼내면?
template<typename T>
void MyArray<T>::print()
{
    for (int i = 0; i < m_length; ++1)
        std::cout << m_data[i] << " ";
    std::cout << std::endl;
} // 이렇게 사용하자.   
``` 

if print() 함수를 MyArray.cpp에 정의를 하면? 
위와 같이 사용하면 main.cpp에서 링킹 에러 발생.  

main에서 MyArray.h를 include하면 MyArray.h의 내용물들이 전부 main.cpp로 복사해서 붙여진 것처럼 작동을 함.  
myarray<char>이 myarray라는 클래스를 char라는 데이터 타입에 대해서 instantiation을 해야 되는구나라는 것까지 컴파일러가 알 수 있음.   
문제는 print라는 함수의 바디를 컴파일 할 때는 MyArray.cpp에서 컴파일 진행이 됨. 따라서 Main.cpp는 헤더파일만 include하기 때문에 MyArray.cpp에 있는 내용을 모름. print란 멤버 함수를 instantiation할 때 char로 해야 하는지 모름.  


### 해결 방법1
main에 #include MyArray.cpp하면 해결. 그런데 코드가 복잡해지면 별로.  

### 해결 방법2
MyArray.cpp를 컴파일 할 때 char 타입으로 특정한 데이터 타입으로 컴파일해야 한다고 알려줘야 함. 
이게 바로 explicit instantiation.   

```cpp
//MyArray.cpp에서
template void MyArray<char>::print();
template void MyArray<double>::print(); 
```
위와 같은 방법은 print 함수처럼 특정 함수에만 적용, 만약 전체 class에 대해서 진행하고 싶으면?  

### 해결 방법3
```cpp
//MyArray.cpp에서
template class MyArray<char>;
template class MyArray<double>;
```
